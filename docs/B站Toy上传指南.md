## 一、先申请权限

1. 打开 https://www.bilibili.com/toy/intro
2. 用你的 B 站账号申请「Toy 平台权限」（内测需要开通）
3. 通过后打开发布页：https://www.bilibili.com/toy/publish

> 官方还提供了一个给 Agent 用的格式校验 skill：
> https://www.bilibili.com/toy/publish/sdk/skill
> 如果你在 B 站能看到这个页面，**建议把里面的规则再对照一遍**（我这边网络连不上 bilibili，没法替你核对）。

## 二、要用哪个包

| 文件 | 大小 | 说明 |
|---|---|---|
| **`奶娃-单文件版.zip`** | **0.77 MB** | ⭐ 推荐。整个游戏就一个 `index.html`，素材全部内联 |
| `奶娃-多文件版.zip` | 0.78 MB | `index.html` + `assets/`（18 个文件），适合要求标准目录结构的平台 |

两个包都已做到：

- ✅ **零外部请求**（没有 CDN、没有外链、没有字体外链）
- ✅ 断网可玩（实测：屏蔽全部 http/https 后，13 张立绘全部就绪、可开局、可发射、可结算）
- ✅ 远低于 **50MB** 限制
- ✅ 入口文件是根目录的 `index.html`

1. 打开 https://www.bilibili.com/toy/publish
2. 上传 `奶娃-单文件版.zip`（或解压后把文件夹整体拖进去，看平台要求）

4. 填写信息：

| 字段 | 建议内容 |
|---|---|
| 标题 | 奶系弹珠 · 弹射讨伐 |
| 简介 | 弹弓 × 合成 × 打 BOSS。拖右摇杆蓄力发射奶球，同类奶球相撞合体升级，打空 8 只 Boss。手机横屏体验最佳。 |

| 封面 | `封面_16x9.jpg`（1920×1080），若要求方形用 `封面_1x1.jpg` |
| 分类 | 休闲 / 动作（按平台选项就近选） |

5. 提交 → 拿到可访问的 B 站链接 → 发动态/视频引流

## 五、已经在代码里做过的适配

| 场景 | 处理 |
|---|---|
| 被 iframe 嵌入、全屏 API 不可用 | 自动**隐藏全屏按钮**，不会点了没反应 |
| 设备不支持方向锁定（iOS） | 已有兜底：显示「横过来」提示 + 「仍要竖屏游玩」 |
| localStorage 被禁用（部分内嵌环境） | 所有读写都在 try/catch 里，读不到就用默认值 |
| 音频自动播放限制 | 必须玩家点击后才初始化音频（已实现） |
| 刘海屏 / 安全区 | 用 `env(safe-area-inset-*)` 留边 |
| 竖屏 | 弹「请横屏」提示，可选继续竖屏玩 |

## 十、资源的生成方式

封面/图标不是手绘的，是脚本生成的（可复现）：

\\\
tools/toy_icons.py     # 奶蛋图标：6x 超采样 + 抹除原眼 + 重画清晰眼睛
\\\

运行：\python tools/toy_icons.py\ → 输出到 \dist/toy/\

关键点：原贴图只有 267×298，直接放大到 500 会糊。
脚本先放大 6 倍再锐化，并把模糊的原眼睛重新画成矢量级干净眼睛，
所以缩到 80px 依然能看清表情。

## 十一、图标定稿说明

最终图标 = 你自己做的那张（蓝底 / 金球 / 绿眼 / 微笑），500×500，直接上传。

体检数据（500px 原图）：

| 指标 | 数值 | 评价 |
|---|---|---|
| 球体直径 | 77.1% 画布 | 留白 9~12%，圆角遮罩不会切到主体 ✅ |
| 球面配色 | 顶部 255,218,91 → 底部 226,174,58 | 有体积感 ✅ |
| 虹膜 vs 球面亮度对比 | ≈1.27:1 | 偏低，主要靠黑瞳孔区分 |
| 嘴线宽度 | ≈2px（500px 下） | 80px 时约 0.3px，几乎只剩一条淡线 |
| 背景亮点（星星） | 4528 像素 | 48px 下会变成脏点 |

**可选优化（不改也能用）**：

1. 虹膜压深 10~15%（如 149,176,100 → 132,158,86），小尺寸下眼睛更清楚
2. 嘴线加粗到 3~4px，并加深到 110,66,24
3. 去掉背景星星，只留纯色渐变

> 试过自动叠画优化，但会和原嘴线错位（出现双线），所以最终**原样采用**你的图。
> 要做上面任一项，基于你的源文件改效果最好。

## 十二、图标背景：梦幻浅蓝

按需求换成浅蓝底，两个版本：

| 版本 | 背景 | 说明 |
|---|---|---|
| **浅蓝**（推荐） | 天蓝渐变 208,238,255 → 150,202,243 + 柔光斑 | 梦幻通透 |
| 蓝紫（备选） | 浅蓝 → 淡紫 198,204,250 | 更少女 |

**浅底的关键处理**：金色球和浅蓝的亮度差很小 —— 原图直接放上去，
球与背景对比只有 **0.89:1**，几乎糊成一片。所以额外加了三层：

1. **描边** 44,78,108 / 3px —— 描边与背景对比 **3.17:1**（达到图形元素 3:1 标准）
2. **投影** 向下偏移 10px、40,78,116 / 105 透明度 / 16px 模糊
3. **光晕** 球外一圈 42 透明度白色，做出「浮在天上」的感觉

实测 80px 缩略图下球体轮廓清晰、表情可辨。
生成脚本：`tools/toy_icon_bg.py`
