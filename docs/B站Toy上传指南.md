# B站 Toy 平台上传指南 · 奶系弹珠

> 上传包已经做好，在 `dist/toy/`。**单文件版优先**（最省事、最不容易出错）。

---

## 一、先申请权限

1. 打开 https://www.bilibili.com/toy/intro
2. 用你的 B 站账号申请「Toy 平台权限」（内测需要开通）
3. 通过后打开发布页：https://www.bilibili.com/toy/publish

> 官方还提供了一个给 Agent 用的格式校验 skill：
> https://www.bilibili.com/toy/publish/sdk/skill
> 如果你在 B 站能看到这个页面，**建议把里面的规则再对照一遍**（我这边网络连不上 bilibili，没法替你核对）。

---

## 二、要用哪个包

| 文件 | 大小 | 说明 |
|---|---|---|
| **`奶娃-单文件版.zip`** | **0.77 MB** | ⭐ 推荐。整个游戏就一个 `index.html`，素材全部内联 |
| `奶娃-多文件版.zip` | 0.78 MB | `index.html` + `assets/`（18 个文件），适合要求标准目录结构的平台 |

两个包都已做到：

- ✅ **零外部请求**（没有 CDN、没有外链、没有字体外链）
- ✅ 断网可玩（实测：屏蔽全部 http/https 后，13 张立绘全部就绪、可开局、可发射、可结算）
- ✅ 远低于 **50MB** 限制
- ✅ 入口文件是根目录的 `index.html`

---

## 三、上传步骤

1. 打开 https://www.bilibili.com/toy/publish
2. 上传 `奶娃-单文件版.zip`（或解压后把文件夹整体拖进去，看平台要求）
3. 等待格式校验通过
4. 填写信息：

| 字段 | 建议内容 |
|---|---|
| 标题 | 奶系弹珠 · 弹射讨伐 |
| 简介 | 弹弓 × 合成 × 打 BOSS。拖右摇杆蓄力发射奶球，同类奶球相撞合体升级，打空 8 只 Boss。手机横屏体验最佳。 |
| 标签 | 独立游戏、弹珠、合成、休闲、单机 |
| 封面 | `封面_16x9.jpg`（1920×1080），若要求方形用 `封面_1x1.jpg` |
| 分类 | 休闲 / 动作（按平台选项就近选） |

5. 提交 → 拿到可访问的 B 站链接 → 发动态/视频引流

## 五、已经在代码里做过的适配

| 场景 | 处理 |
|---|---|
| 被 iframe 嵌入、全屏 API 不可用 | 自动**隐藏全屏按钮**，不会点了没反应 |
| 设备不支持方向锁定（iOS） | 已有兜底：显示「横过来」提示 + 「仍要竖屏游玩」 |
| localStorage 被禁用（部分内嵌环境） | 所有读写都在 try/catch 里，读不到就用默认值 |
| 音频自动播放限制 | 必须玩家点击后才初始化音频（已实现） |
| 刘海屏 / 安全区 | 用 `env(safe-area-inset-*)` 留边 |
| 竖屏 | 弹「请横屏」提示，可选继续竖屏玩 |

## 七、如果平台审核打回

常见原因和对策：

| 打回原因 | 处理 |
|---|---|
| 引用了外部资源 | 用**单文件版**（素材全内联，绝对没有外链） |
| 文件超限 | 现在 0.77MB，不可能超 |
| 入口不是 index.html | 两个包都是根目录 `index.html` |
| 移动端适配不足 | 已有横竖屏两套布局 + 摇杆触控 |
| 需要版号/资质 | 这是**非商业内测**，按平台要求填即可 |

**启动图 vs 封面的区别**：

- **启动图**：五个角色一字排开，适合作品列表缩略图，一眼看出是"奶系"游戏
- **封面**：实机战斗画面，适合详情页大图，能看到玩法

两个都传，平台让你选哪个用哪个。
