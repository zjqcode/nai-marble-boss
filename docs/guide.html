新手指南

3 分钟知道该干什么
你要做的事只有一件：把 Boss 的血条打空，同时别让自己的心掉光。 其他一切（合成、道具、破防）都是为这件事服务的。

1两个摇杆

摇杆怎么用
左（左下）左右拖动 → 奶娃左右跑。上下推没用
右（右下）往下拉蓄力，松手发射；左右偏可调角度

记住：下拉 = 蓄力，松手 = 发射。

2核心循环

发射奶球 → 撞 Boss → 掉落奶球 → 同类同级相撞合体升 1 级 → 等级越高伤害越高。

发射→ 撞 Boss→ 掉球→ 合体升级→ 更痛

别一直用小奶球磨：5 级球伤害是 1 级的 8 倍。先让球在场上互相撞、合并，你才能真正打疼它。

3打哪里

目标效果
弱点板（发光圆点）伤害 ×1.5 ✅ 尽量都打这里
身体其他部位只有 ×0.35，但会积累「破防」

破防条满了 → Boss 硬直几秒，这时打哪都算弱点。所以打身体也不算白打。

4怎么不被打死

Boss 出招前地面会出现红色危险区：

  • 看到红区 → 立刻用左摇杆走出去
  • 红区快满时才离开 = 极限闪避（分数 ×3 + 额外奶瓶）
  • 被命中 → 扣心 + 眩晕（0.5~0.9 秒动不了）
站着不动 = 必被砸。这是新手最常见的死因。

5别乱发球

一整发球没碰到 Boss 就掉出底部，算「空放」：装填变慢 8%，连续空放最多慢 45%；打中 Boss 立刻恢复。

所以：瞄准了再发，乱按只会越打越慢。

6道具

道具作用
🍼 血瓶回血，必买
⚡ 多球一次发 3 颗
▭ 反弹板底部挡板，球不会掉
⏱ 加时奶糖+10 秒（可叠 6 个）
🔥 火球 / 🌀 传送门增伤 / 捷径
⚡ 雷击 / ✨ 变身爆发，Boss 残血时用

7新手 5 条

1先只练一件事：把球打到发光圆点
2别急着发力，先让球合到 3~4 级再连续射
3红区永远优先于输出：先躲，再打
4血瓶留到 2 颗心以下再喝
5前两关很宽松（90 秒、攻击慢），拿它们练手感

8输赢规则

  • 赢：Boss 血条打空
  • 输：心掉光，或者时间到
  • 限时：90 / 85 / 80 / 75 / 70 / 65 / 60 / 60 秒（第 1 → 8 关）
