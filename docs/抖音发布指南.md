# 抖音发布指南 · 奶系弹珠

> 这游戏是**横屏**玩的（竖屏只是"仍要竖屏游玩"的兜底）。
> 所以视频做法是：**录横屏画面 → 剪到 9:16 画布里 → 上下加标题和字**。
> 这也是所有横屏游戏在抖音的标准做法。

---

## 一、录屏（横屏，2 分钟）

### 手机录屏（推荐）

1. 手机打开 `https://naiwadanzhu.surge.sh`
2. 点 **开始讨伐** → 进关后点右上角 **⛶ 全屏**（录出来没有浏览器地址栏）
3. **把手机横过来**，开系统录屏（iPhone 控制中心 ●；安卓下拉「屏幕录制」）
4. 按下面脚本玩一遍，录 **40~60 秒**
5. 结束录制

> ⚠️ **不要用「仍要竖屏游玩」录** —— 那是兜底布局，画面上下空一大块，
> 也不符合真实手感（两只摇杆本该在左右两侧）。

### 电脑录屏（画质更高）

- `Win + G` 游戏栏 / OBS，录 16:9 横屏
- 后期同样放进 9:16 画布

## 二、剪辑（剪映，5 分钟）

1. 剪映 → **开始创作** → 选录屏
2. 底部工具栏 → **比例** → **9:16**
3. 点视频片段 → **背景** → **画布模糊**（第二档够用）
4. 双指把视频放大到**宽度撑满**，上下留出文字区
5. 加文字（默认黑体加粗、描边 2px）：
   - 顶部：`我做了个 奶系弹珠`
   - 中下：`横屏 · 弹弓蓄力 · 合成打 BOSS`
6. 导出：**1080P / 30fps / 关闭水印**

> 想更精致：剪映「素材」搜「手机横屏」「Switch」素材包，把画面套进设备框。

### 视频脚本（20 秒版）

| 时间 | 画面（横屏录制） | 字幕 |
|---|---|---|
| 0-2s | Boss 笑脸特写推近 | **这是我自己做的游戏** |
| 2-5s | 右摇杆下拉 → 松手 → 球飞出撞 Boss | 下拉蓄力，松手发射 |
| 5-9s | 两颗同级球相撞 → 合并升级闪光 | 同类相撞 → 合体升级 |
| 9-13s | 高等级球连撞，伤害数字狂跳 | 5 级球伤害是 1 级的 8 倍 |
| 13-16s | 红区亮起 → 横移躲开 → 闪避提示 | 红区亮起就跑 |
| 16-19s | 结算「BOSS DEFEATED」 | 一关 60 秒左右 |
| 19-20s | 标题 + 网址 | 网页版，打开就能玩 |

**15 秒精简版**：砍掉 5-9s 合体细节，只留「发射 → 命中 → 闪避 → 通关」。
**45 秒加长版**：结尾补「无尽模式 8 连战」，8 只 Boss 立绘快切，很抓人。

## 五、发布步骤

1. 抖音 App → 底部「+」→ **上传**（不是"拍同款"）
2. 选视频 → **封面**用 `封面_C_横屏框.jpg`
3. **配乐**：抖音曲库搜「轻快/卡点」，音量 30%（游戏原声留 70%）
4. 贴标题 + 话题
5. 高级设置：允许下载 ✓ 同步西瓜/头条 ✓
6. 发布 → 立刻去评论区发那条 URL

**最佳时段**：12:00-13:00 / 18:00-20:00 / 21:00-23:00

## 七、注意事项

1. **视频是竖屏 9:16，画面是横屏** —— 别直接传横屏视频（会带黑边）
2. **前 3 秒必须有动作**（Boss 笑脸 / 球飞出），别放 loading
3. **BGM 只用抖音曲库**，外部音乐会被判侵权限流
4. 导出**关闭剪映水印**，也别出现其他平台水印
5. 游戏里有「奶屎」「放屁」这类词，**标题别写**，画面一闪而过没事
6. 一条视频只讲**一个**卖点
7. **画面和文案里都不要出现网址、二维码、其他平台名**（会被判站外导流）

## 九、关于"怎么让人玩到"（重要）

抖音对站外导流管得很严，所以**这个视频里不出现任何链接/二维码**是对的。
想真的转化，按下面优先级来：

| 优先级 | 做法 | 说明 |
|---|---|---|
| ★★★ | 同步发 **B站 / TapTap / 知乎** | 这几个平台允许放链接，把主阵地放那边 |
| ★★☆ | 抖音主页做成"搜索词" | 视频口播「奶系弹珠，主页有」，别打字幕网址 |
| ★★☆ | 抖音做系列合集 | 3~5 条视频形成"合集"，涨粉后主页权重更高 |
| ★☆☆ | 上架抖音小游戏 | 唯一"点开就玩"，但要企业主体 + 工程改造 |

> 如果以后确实需要在视频里露出入口，优先考虑**抖音小游戏**这条正规路，
> 而不是想办法绕过审核 —— 绕过的代价通常是账号。
